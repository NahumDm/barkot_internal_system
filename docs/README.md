# Documentation

- `architecture/` — software architecture specification and system/data architecture diagrams.
- `ui-ux/` — UI/UX design specification. The design contract for the dashboard, inventory, finance and payroll modules.
- `api/` — API reference and OpenAPI output.
- `business/` — business process notes, data definitions and client decisions.
- `runbooks/` — operational procedures: deployment, backup, restore, incident response.

The specifications in `architecture/` and `ui-ux/` are the source of truth. Do not introduce business concepts, metrics or workflows that they do not define.
