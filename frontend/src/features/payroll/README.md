# payroll

Employees, monthly payroll and deductions.

Employees: Full Name, Position, Phone, Start Date, Monthly Wage, Status.
Payroll: month navigation, KPI cards (Monthly Payroll, Employees, Paid, Pending), employee table with Basic Wage, Additions, Deductions, Net Pay, Status.
Every deduction requires a reason and must affect its payroll period (spec §14.2).
